---
title: Install Layerfold
description: Install Layerfold on Windows, or build it from source.
order: 10
---

Layerfold has a Windows x64 installer. It isn't code-signed, so Windows warns about an unknown
publisher the first time.

To build it yourself, follow [Building](../../../README.md#building) in the README. Other systems
aren't tested.

Settings stay in `%APPDATA%\Layerfold`. The first launch copies them from an EffectCraft installed
on the same computer, and EffectCraft keeps its own.
